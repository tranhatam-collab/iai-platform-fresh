# IAI UI TEXT SYSTEM
## Locked Interface Language Standard for *.iai.one
## Version 1.1 (Locked)

---

## 0. PURPOSE

UI text is not decorative language.
UI text is the direct operating layer between system and human.

Therefore UI text across IAI must be:
- short
- clear
- calm
- non-emotional
- non-sales
- non-manipulative
- role-aligned
- structurally consistent

This document is the UI language source of truth.

---

## 1. GENERAL PRINCIPLES

### 1.1 Vietnamese
- full diacritics required
- 2–4 words ideal for labels and buttons
- no exclamation marks
- no slang
- no emotional padding

### 1.2 English
- 1–3 words preferred for labels
- no advertising words
- no consumer-app friendliness theatre
- no “magic” language

### 1.3 Tone
- calm
- exact
- credible
- structured
- non-urgent

## 16. PROMPT FOR AI UI GENERATION

Generate UI text for an IAI surface.

Rules:
- Vietnamese first, English second
- Calm, precise, institutionally credible
- 2–4 words for buttons and labels
- No sales language
- No hype
- No emotional tone
- No hard-coded wording outside the shared codex
- Must align with constitutional trust, proof, structure, boundaries, and long-term continuity

---

## 17. DEV RULE

All public UI text must be bound from:
- `/content/vi.json`
- `/content/en.json`

Do not hard-code:
- menu
- button
- badge
- status
- error
- footer
- form labels
- helper text

---

## 18. QA RULE

Reject if:
- thiếu dấu tiếng Việt
- EN quá marketing
- có từ cấm
- button quá dài
- badge sai hệ
- CTA ngoài registry
- không đúng vai surface

---

## 19. FINAL RULE

Every visible word in the interface must have a reason to exist.
No word exists only to decorate.
