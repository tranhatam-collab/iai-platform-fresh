## File naming
- Daily: `DAILY_<team-code>_YYYY-MM-DD.md`
- Weekly: `WEEKLY_<team-code>_YYYY_WW.md`
- Audit/incident: `*_AUDIT_REPORT_YYYY-MM-DD.md`, `P0_CLOSURE_REPORT_YYYY-MM-DD.md`
