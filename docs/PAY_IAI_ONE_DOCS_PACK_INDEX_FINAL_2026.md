0. Core statement

This file is the final repository-ready documentation pack index for pay.iai.one.

Its purpose is simple:

if a team member, AI builder, reviewer, or operator opens only one document to understand where to start, what to read, what to update, and what remains pending, this must be that document.

This file does not replace the master project index.
It sits above the whole docs pack as the navigation shell for the lane.

It tells the team:

* what the docs pack contains
* what each file is for
* which file is the actual entry point
* what must be read first
* which templates are operational
* which dependencies are still pending
* how the whole pack should be used in the repo

3. Pack structure overview

The pay.iai.one docs pack is divided into 7 layers:

Layer A — Command and entry

Defines where the lane starts and what controls everything else.

Layer B — Pack usage protocol and integration verification

Defines how the docs pack must be used in real day-to-day work and how its repo integration must be verified.

Layer C — Core implementation reading pack

Defines the architecture, build order, and detailed implementation reading path.

Layer D — Team execution onboarding and delivery overlay

Defines where each team enters after reading the command layer and how the lane can be compressed into a 3-team execution model when needed.

Layer E — Governance templates

Defines how the team reports, logs decisions, and proves release readiness.

Layer F — Daily execution templates

Defines how the team tracks active work and live risks.

Layer G — Activation and onboarding operations

Defines how the team onboards websites, legal owners, collection accounts, and payout accounts into the pay.iai.one operating model.

Layer H — Pending locked dependencies

Defines the critical files that are expected by the docs architecture but not yet materialized in this repo cycle.
