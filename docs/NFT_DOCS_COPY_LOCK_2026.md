## /docs/verification

### H1
NFT verification standard

### Copy
IAI NFTs are verifiable asset and credential records. Each issued token links issuer, subject, chain record, metadata hash, asset hash, proof document, signature and public status.

Verification does not mean financial value. It means the record can be checked independently.

---

## /docs/issuance-policy

### H1
Issuance policy

### Copy
A token can be issued only when issuer, subject, wallet, proof, metadata hash, asset hash and audit record exist.

Preview records are not issued records. A preview cannot be used as a verified credential.

---

## /docs/revocation-policy

### H1
Revocation policy

### Copy
Revocation changes the credential status of a token. It does not erase the blockchain record.

A token may be revoked, disputed, replaced or expired when the original proof is no longer valid.

---

## /docs/public-registry

### H1
Public registry

### Copy
The public registry allows anyone to verify issued IAI tokens by collection, token ID, wallet, issuer and status.

The registry is for verification. It is not a marketplace.
